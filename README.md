# 地図探検

地域の地図を見ながら、地図記号や施設の位置、周りの様子を調べるためのWeb教材です。

小学3年生の社会科「地域のようす」の学習を中心に、身近な地域を地図から探検する活動を想定しています。検索した場所を中心に、周辺の施設を地図上で確かめることができます。

## この教材で大切にしていること

「施設を検索するアプリ」ではなく、「地図を読む教材」として使えることを重視しています。

特に、国土地理院の淡色地図を土台にして、地図上に表示されている地図記号を主役にしています。

対応する地図記号がある施設については、施設名や文字を地図の上に重ねて表示するのではなく、透明なタップ領域だけを重ねます。そのため、地図そのものの記号を隠さずに、記号をタップして施設情報を確かめられます。

施設をタップすると、次の動きになります。

1. 地図上の施設が選択状態になる
2. 地図がその施設を中心に表示する
3. 右側の施設一覧で、その施設が一番上に移動する
4. 地図と一覧の両方で選択状態を色で確認できる

「地図で見つける → タップして確かめる → 周りと比べる → 気づいたことを残す」という流れで使います。

## 主な機能

### 地図で探す

検索欄から学校・駅・公園・市役所・図書館などの場所を検索します。

検索した場所を基準地点として、周辺の施設を取得します。地図上には500mの円を表示し、施設までの距離は基準地点からの直線距離で表示します。

施設一覧では、公共施設、くらし、健康・福祉、教育、地域などの分類で絞り込めます。

「見つけた！」の記録と「気づいたこと」のメモは、ブラウザのlocalStorageに保存します。

### 地図の操作

地図はタップ・ドラッグで移動できます。

「＋」「−」で拡大・縮小できます。対応する端末では、2本指の操作で地図を拡大・縮小できます。

「基準地点にもどる」で検索した場所を中心に戻せます。

「地図をひろげる」で地図を大きく表示できます。

## 使用している地図・施設データ

### 地図：国土地理院 地理院タイル

背景地図には国土地理院の「淡色地図」を使用しています。

淡色地図はズームレベル5～18で提供されています。本教材では、地域の施設や地図記号を確認しやすい縮尺を中心に利用します。

地理院地図のズームレベル15～17では、電子地形図25000の地図記号が準用されています。

出典：
https://maps.gsi.go.jp/development/ichiran.html

### 施設情報：OpenPOI API

周辺施設の検索にはOpenPOI APIを使用しています。

OpenPOI APIはAPIキー不要、ブラウザから利用でき、CORSにも対応しています。

取得した施設情報は、教材内で扱いやすい分類・距離・方位などに整理して利用しています。

出典・ライセンス：
https://openpoiapi.com/attribution.html

## データの扱い

施設データはOpenPOI APIから取得します。

同じ施設が複数のデータとして返ってくる場合があるため、施設名と位置を使って近い重複データを整理しています。

取得した周辺施設は一定時間localStorageにキャッシュします。再読み込み時には保存されたデータを利用できるため、同じ場所を続けて調べるときの通信を減らせます。

施設データは常に完全とは限らないため、「地図に表示されない＝その施設が存在しない」とは判断しません。

## プライバシー

「気づいたこと」「見つけた！」の状態、検索した基準地点などは、この端末のブラウザ内に保存します。

児童の氏名や学級情報などをサーバーへ送信する機能はありません。

授業や家庭で使用する際には、自宅など個人が特定される場所を入力・共有することには注意してください。

## 技術構成

HTML / CSS / Vanilla JavaScriptで構成しています。ビルド環境やバックエンドは使用していません。

外部APIは施設情報の取得にOpenPOI API、背景地図に国土地理院の地理院タイルを使用します。

### ファイル構成

```
index.html
style.css
app.js
config.js

data/
  category-map.js
  poi-service.js
  presets/

geo/
  geo.js

state/
  store.js

ui/
  map.js
```

### 各ファイルの役割

- `config.js`
  地図の初期ズーム、検索範囲、表示件数、キャッシュ時間、基準地点、地理院タイルURLなどの設定をまとめています。

- `data/poi-service.js`
  OpenPOI APIとの通信、施設データの正規化、重複整理、キャッシュを担当します。

- `data/category-map.js`
  OpenPOIから取得した施設名・カテゴリなどを、教材用の分類と地図記号タイプに整理します。

- `geo/geo.js`
  緯度経度からの距離・方位計算と、地図上の座標変換を担当します。

- `state/store.js`
  localStorageへの保存・読み出しを担当します。

- `ui/map.js`
  国土地理院の地理院タイルの表示、地図の移動・拡大縮小、500m円、施設の透明タップ領域、選択状態などを担当します。

- `app.js`
  検索、施設一覧、地図、フィルター、メモなどをつなぐ全体の進行を担当します。

設定値はできるだけ `config.js` にまとめ、各機能を役割ごとに分けて、あとから教材内容を修正しやすい構成にしています。
