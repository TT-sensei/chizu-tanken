# 地図探検

「地図で地域を知る」ための、小学3年生向け社会科のWeb教材です。

学校や駅、公園などの場所を検索すると、その周辺を国土地理院の淡色地図で探検できます。地図記号を見つけたり、施設の場所や距離、方位を確かめたりしながら、地域の様子に気づいていくことをねらいとしています。

先生が授業前に地域の施設を調べたり、教材用の地図を作ったりしなくても、場所を検索するだけですぐに活動を始められることを大切にしています。

## ねらい

この教材の中心は「施設検索」ではなく「地図を見ること」です。

地図を見て、
「どこに何があるか」
「どんな施設が集まっているか」
「学校からどちらの方向にあるか」
「近くにどんな場所があるか」
などを、自分で見つけていきます。

児童の基本的な流れは、

地図を見る
→ 地図記号や施設を見つける
→ 気になる場所をタップする
→ 施設名・距離・方位を確かめる
→ 「見つけた！」を記録する
→ 気づいたことを残す

です。

クイズに答えることを中心にせず、地図そのものを見て発見する体験を重視しています。

## 主な機能

### 地図で探す

場所を検索すると、その地点を中心に周辺の施設を表示します。

検索結果から学校、駅、公園、市役所、図書館などの場所を選ぶことができます。前回選んだ場所はこの端末に記録されるため、同じ端末なら次回も利用しやすくなっています。

### 国土地理院の淡色地図

背景地図には国土地理院の地理院タイル「淡色地図」を利用しています。

淡色地図はズームレベル5～18で提供されています。ズームレベル15～17には電子地形図25000の地図記号が使われています。

地図記号が主役になるよう、対応する施設では施設名や独自アイコンを地図の上に重ねません。透明なタップ領域だけを重ね、下にある地図の記号を見たままタップできるようにしています。

地図記号をタップすると、その施設を選択状態にして地図をその場所へ移動します。右側の施設一覧でも、その施設が一番上に移動し、選択状態が色で分かります。

### 周辺の施設

OpenPOI APIから周辺施設を取得し、教材用に分類しています。

公共施設、くらし、健康・福祉、教育、地域などの分類で絞り込めます。

施設名、分類、直線距離、8方位を一覧で確認できます。

施設データが地図に存在しないことをもって、その施設が実際に存在しないとは判断しません。POIデータには欠落や重複などがあり得るためです。

### 「見つけた！」の記録

施設ごとに「見つけた！」をチェックできます。

チェックした数は「見つけた 7 / 20」のように表示されます。

探検の進行状況は基準地点ごとに、この端末のブラウザ内へ保存します。

### 探検バッジ

見つけた数や、見つけた施設の種類に応じてバッジを表示します。

現在は、
「はじめての探検」
「地図さがし名人」
「まちを見わたす」
「地域探検マスター」
の4種類を用意しています。

バッジはゲームの得点や順位を競うためではなく、地図の中でどれだけ発見できたかを楽しく振り返るための仕組みです。

今後、授業での使い方に合わせて条件や種類を増やせる構成にしています。

### 気づいたこと

「気づいたこと」は基準地点ごとに保存します。

例えば、
「駅の近くに店が多い」
「学校の周りに公園がある」
「公共施設が同じ方向に集まっている」
など、地図を見て気づいたことを書くために使います。

## 地図の操作

地図はドラッグして移動できます。

「＋」「−」で拡大・縮小できます。対応する端末では、2本指で拡大・縮小できます。

「基準地点にもどる」で検索した場所を中心に戻せます。

「地図をひろげる」で地図だけを大きく表示できます。

500mの円を表示し、基準地点からの範囲を見ることもできます。

距離は道路に沿った距離ではなく、基準地点から施設までの直線距離です。

## データと外部サービス

### 国土地理院 地理院タイル

背景地図に国土地理院の地理院タイルを使用しています。

出典：
https://maps.gsi.go.jp/development/ichiran.html

### OpenPOI API

周辺施設の検索にOpenPOI APIを使用しています。

OpenPOI APIは日本全国のPOIを検索でき、APIキー不要、CORS対応です。

出典・ライセンス：
https://openpoiapi.com/attribution.html

OpenPOIの利用時には、最新の出典・ライセンス条件を確認してください。

## データの保存

検索した基準地点、「見つけた！」の記録、「気づいたこと」はlocalStorageに保存します。

児童の氏名、学級情報などをサーバーへ送信する機能はありません。

探検の進行状況は場所ごとに分けて保存するため、違う地域を調べた場合も記録が混ざりません。

## ファイル構成

```
index.html

badges/
  badges.js

  category-map.js
  poi-service.js
  presets/

geo/
  geo.js

state/
  progress.js
  store.js

ui/
  map.js
```

### 各ファイルの役割

- `config.js`
  地図の初期ズーム、検索範囲、表示件数、キャッシュ時間、基準地点、地理院タイルURLなどをまとめます。

- `data/poi-service.js`
  OpenPOI APIとの通信、施設データの正規化、安定した施設IDの作成、重複整理、キャッシュを担当します。

- `data/category-map.js`
  取得した施設を教材用の分類に整理し、国土地理院の地図記号をそのまま見せる対象かどうかを管理します。

- `geo/geo.js`
  距離・方位の計算と、地図座標への変換を担当します。

- `state/progress.js`
  基準地点ごとの「見つけた！」と「気づいたこと」をlocalStorageへ保存します。

- `state/store.js`
  基準地点など、アプリ全体で使う簡単な保存処理を担当します。

- `badges/badges.js`
  探検バッジの条件と表示情報をまとめます。

- `ui/map.js`
  地理院タイル、地図操作、500m円、透明なタップ領域、選択状態を担当します。

- `app.js`
  検索、施設一覧、発見記録、バッジ、メモなどをつなぐ全体の進行を担当します。

設定や教材内容をできるだけ役割ごとに分け、あとからAIを使って修正しやすい構成を目指しています。

## 公開

GitHub Pagesなどの静的ホスティングで公開できます。

リポジトリ直下に `index.html` がある状態で公開してください。

## 利用上の注意

授業前に、学校のネットワークから次のサービスへ接続できることを確認してください。

- 国土地理院 地理院タイル
- OpenPOI API

また、自宅など個人が特定される場所の検索・共有には注意してください。
